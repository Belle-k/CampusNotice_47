# CampusNotice 校园通知智能管理助手

CampusNotice 是一个基于 Python Flask 开发的校园通知智能管理助手，旨在帮助大学生集中管理分散的校园通知、活动信息和重要时间节点，减少重要通知遗漏，提高校园事务管理效率。

## 一、项目简介

在日常校园生活中，通知信息通常分散在微信群、公众号、网页及各类文档中。学生需要反复查找通知内容，并手动记录报名截止、材料提交等重要日期，容易出现信息遗漏和时间管理不及时的问题。

CampusNotice 通过文件导入、信息提取、通知管理和截止日期管理，将分散的校园通知整理为结构化信息，为学生提供统一、直观的校园通知管理入口。

本项目目前为本地 Web 应用原型，采用 Flask 和 SQLite 实现。

## 二、主要功能

### 1. 首页概览
- 展示校园通知总数。
- 统计待处理事项。
- 展示未来 7 天即将截止的事项。
- 显示最近添加的通知及近期截止事项。

### 2. 智能通知导入
- 支持 PDF、DOCX 和 TXT 文件上传。
- 自动提取文件中的文本内容。
- 根据规则识别通知标题、类别、发布单位及重要日期。
- 对识别结果进行预览和人工修改。
- 确认后将通知及其时间节点保存到数据库。

### 3. 通知管理
- 支持手动新增校园通知。
- 支持编辑和删除已有通知。
- 支持按照标题、类别、发布单位及正文关键词搜索。
- 支持一条通知关联多个时间节点。
- 支持切换截止事项的完成状态。

### 4. 截止日历
- 按月份展示所有截止事项。
- 支持月份切换。
- 直观查看不同日期对应的通知事项。
- 支持直接切换事项完成状态。
- 展示当月事项总数、待处理、已完成及逾期情况。

### 5. 数据统计
- 统计通知总数和通知类别分布。
- 统计截止事项总数。
- 展示待处理、已完成和逾期事项。
- 统计未来 7 天即将截止的事项。
- 计算事项完成率。

## 五、环境配置与运行

### 1. 环境要求

- Python 3.10 或更高版本
- Git
- Windows、macOS 或 Linux

### 2. 克隆项目

```bash
git clone -b develop https://github.com/Belle-k/CampusNotice_47.git
cd CampusNotice_47
```

### 3. 创建虚拟环境

Windows PowerShell：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 4. 安装项目依赖

```bash
pip install -r requirements.txt
```

### 5. 启动项目

```bash
python run.py
```

启动成功后，在浏览器访问：

```text
http://127.0.0.1:5000
```

首次启动时，系统会自动初始化 SQLite 数据库。

## 六、数据存储与使用说明

项目使用 SQLite 保存校园通知及其关联的截止事项。

数据库文件在应用首次启动时自动创建于：

```text
instance/campusnotice.db
```

一条通知可以关联多个截止事项，每个事项分别记录名称、日期、备注和完成状态。

文件导入采用规则提取方式，系统生成的标题、类别、发布单位及日期均为候选信息，用户需要在预览页面检查并确认后再保存。

## 七、Git 分支管理

项目采用 Git 分支管理方式组织开发：

| 分支 | 作用 |
|---|---|
| main | 稳定版本分支 |
| develop | 开发集成分支 |
| feature/* | 功能开发分支 |

项目开发流程：

1. 从 develop 创建功能分支。
2. 在功能分支中进行独立开发。
3. 完成后提交代码并推送至 GitHub。
4. 创建 Pull Request。
5. 检查代码变更后合并到 develop。
6. 在发生分支冲突时，人工检查并解决冲突，再提交合并结果。

项目通过两个独立功能分支修改同一文件，实际演示了 Git 内容冲突的产生、定位和解决过程。

## 九、当前版本的功能边界

当前版本主要实现校园通知的本地整理和时间节点管理，仍有以下限制：

- 文档信息提取基于规则，不能保证所有复杂格式均能准确识别。
- 扫描图片版 PDF 暂不支持 OCR 识别。
- 暂未实现用户账号及权限管理。
- 暂未实现云端数据同步和自动消息推送。

后续可根据实际使用需求，进一步优化文档识别准确性、提醒机制及多用户协作能力。
